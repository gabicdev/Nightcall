# Nightcall 13.1 — primeira macro de reformulação visual

Referências: logo oficial e duas artes conceituais fornecidas pelo usuário. Nenhuma arte foi gerada para o aplicativo: o logo original foi incorporado sem edição.

## Alterações
- Novo design system CSS, fonte do sistema, tons preto/índigo/lavanda, espaçamento, bordas, sombras, foco visível e scrollbars.
- Logo oficial incorporada na tela de login e no ícone da barra lateral; wordmark e mensagem de identidade no painel de navegação.
- Navegação com ícones vetoriais CSS em lugar dos dois principais emojis, mantendo IDs e listeners existentes.
- Painéis padronizados: início, amigos, DMs, conversa, comunidades, configurações e janelas modais.
- Responsividade para telas menores; compatibilidade com reduzir movimento.
- Assets copiados no build e incluídos no pacote Electron.

## Limites
Este pacote **não representa a arte conceitual como se fosse uma tela implementada**. Os dados e funções continuam sendo os recursos reais da aplicação. Não inclui layout GoLive igual ao conceito nem testes visuais no Windows. Não contém EXE compilado; continua com o gerador existente. Validação realizada: testes Node e build estático.
