# Macro Nightcall 3.7 → 4.0

- 3.7: revisão da configuração Electron, inicialização do backend somente em modo local.
- 3.8: modo opcional de servidor remoto HTTPS por configuração persistente/variável de ambiente.
- 3.9: validação estrita de origem remota e testes de regressão de configuração.
- 4.0: consolidação de versão, documentação e script de empacotamento Windows mantido.

Sem Windows e conexão de produção, não é possível atestar `.exe` compilado, instalação, voz, tela ou comunicação entre PCs.
